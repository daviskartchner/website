QR Code Generator API

Usage

To generate a QR code, use the following URL format:

https://daviskartchner.com/qrcode/generate.html?data=[your-data]&type=[type]

Parameters:

  • data (required): The content to encode in the QR code
  • type (optional): Output format
    • svg (default) - Returns SVG format
    • png - Returns PNG format
    • url - Returns URL format

Examples:

  • Generate SVG QR code: https://daviskartchner.com/qrcode/generate.html?data=Hello%20World
  • Generate PNG QR code: https://daviskartchner.com/qrcode/generate.html?data=Hello%20World&type=png
  • Generate URL QR code: https://daviskartchner.com/qrcode/generate.html?data=https://example.com&type=url
